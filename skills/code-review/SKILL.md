# Code Review

Use this skill when asked to review code changes before they are merged or shipped.

## Process

1. Inspect the relevant diff or files before making claims.
2. Prioritize correctness, security, data loss, and regression risks.
3. Report concrete findings with file and line references when possible.
4. Avoid style-only feedback unless it blocks maintainability or violates local conventions.
5. If no substantive issues are found, say so clearly and mention what was checked.
