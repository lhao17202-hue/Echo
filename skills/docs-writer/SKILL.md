# Documentation Writer

Use this skill when adding or updating user-facing or contributor-facing documentation.

## Process

1. Read nearby documentation before editing so tone and structure match.
2. Prefer short, task-oriented explanations over broad background.
3. Include exact commands, file paths, and expected outcomes when documenting workflows.
4. Keep examples minimal but runnable.
5. Remove stale wording instead of adding contradictory notes.
